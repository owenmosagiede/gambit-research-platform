# Gambit brand assets

Supplied by Gambit Design System 1.0 (review edition). The original token and CSS files are retained here. Logo SVGs and font binaries are copied unchanged. Inter and IBM Plex Mono license notices accompany the distributed fonts. Archivo is not distributed; its outlined wordmark needs no font.

`../gambit-theme.css` adapts this visual foundation to the existing platform. Existing layouts, scientific labels, controls and research behavior remain authoritative. The kit specimen does not add a Research Spec selector.
