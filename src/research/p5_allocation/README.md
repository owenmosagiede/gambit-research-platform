# P5 shared-capital allocation boundary

The user confirmed that P4 constructs individual trading sleeves and P5 allocates shared
capital across sleeves. This directory reserves the P5 implementation location only.

Exact allocation mathematics, aggregate constraints, capital feedback to P4 and final
feasibility checks remain unresolved in [specification 09](../../../specs/09_p5_and_execution_boundary.md).
No P5 computation or execution authority is implemented by the presence of this directory.
